<details><summary><code>cc1</code> Fidelity Chess Challenger 1</summary>

**Known limits**

- No history replay: its DM entries refuse captures.
- No setup mode: games start from the start position (cc3 replays a history from the start).

- MAME set `cc1` (Chess Challenger), driver `fidelity/cc1.cpp`
- script runs `mess cc1`
- interface `cc1.lua`
- retro.ini: elo 810, levels 1, ponder/brain n

**Levels:** 5s move
